# Draft 2027 plan — files you can open

These are **draft** 2027 figures from the Command Center. They are not an approved budget.

**Easiest:** open `1st-Class-Plumbing-2027-Draft-Plan.html` in any browser (Chrome, Safari, Edge). Use the tabs at the top to jump around.

If you want Excel or Google Sheets:

- `1st-Class-Plumbing-2027-Draft-Plan.xlsx` — full workbook
- `01-goals.csv` through `06-cash.csv` — one sheet each, File → Import in Google Sheets
- `1st-Class-Plumbing-2027-Draft-Plan.zip` — everything above in one file

The 10% growth reserve is a cash allocation from profit, not an operating-expense line.
